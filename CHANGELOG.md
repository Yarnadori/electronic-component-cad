# Changelog

## 0.1.2

- Document Python and uv requirements before installation, with setup and verification commands.
- Remove the Python 3.11 pin; keep the supported CPython range at 3.11–3.13 and retain the dependency lock.
- Add a Python compatibility CI matrix, contributor guidance and clear update/troubleshooting instructions.

## 0.1.1

- Keep code, references, environments and caches in persistent workspaces outside user projects.
- Reuse a workspace for the same project and output only `models/<part-number>/` into it.
- Keep internal setup details out of normal model documentation and recommend personal skill installation.

## 0.1.0

- Initial public Agent Skills package for CadQuery + uv electronic-component modeling.
- Include a standalone starter, colored STEP validation, preview rendering, templates and English/Japanese setup guides.
